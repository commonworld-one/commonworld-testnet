# Integration and partnership status

This page prevents a technical experiment or application from being mistaken for a partnership.

## Status definitions

| Label | Meaning | Evidence required |
|---|---|---|
| Candidate | Considered for compatibility or strategy | Research note only |
| Contacted | A real request/message was sent | Date and organization; redact private details |
| Discussion | A two-way exchange occurred | Public source or authorized summary |
| Pilot | Bounded joint test agreed | Scope, participants, dates and success criteria |
| Integration | A working product integration exists | Public technical evidence and maintainer confirmation |
| Partnership | Both parties authorize the relationship claim | Written approval or joint public announcement |

## Current public record

The materials reviewed for this repository establish testnet experiments and integration candidates, but do not establish a confirmed external partnership with Circle, Chainlink, Hyperlane, Safe, Uniswap, Chainlist, a game, or an application.

Chainlist is a listing process; Safe singleton factory support is a deployment request process. They are not endorsements or partnerships. Chainlink-compatible interfaces and Circle-related bridge research do not establish a Chainlink feed or Circle-issued asset on this network.

Update this page only when the status changes and the evidence can be linked. Use the narrowest accurate wording.
